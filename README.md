# 表格整理台

一个本地运行的 Excel 评论整理网站：按模板表拆分评论，使用 DeepSeek 复核表头、列映射和评论行结构，在网页中修改结果，再导出沿用模板样式并带原始来源页的工作簿。

## 本地使用

需要 Python 3.10 或更高版本。进入 `excel-assistant/`，按[启动说明](excel-assistant/README.md)安装依赖、配置自己的 DeepSeek API Key 并启动网站。

每位使用者应使用自己的 API Key。Key 放在本机的 `.env` 文件中，不要提交到 GitHub。工作簿也不会提交到仓库。

## 在线发布说明

当前应用需要 Python 后端。GitHub Pages 只发布静态网站文件，不能运行这个后端；若要让所有人通过公开网址直接使用，还需要把后端部署到可运行 Python 的服务，并决定 API Key 是由每位使用者自行提供，还是由站点运营者统一承担调用费用。
